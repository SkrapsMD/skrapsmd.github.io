Geocoder — Batch address-to-coordinates
2026-05-19
Upload a spreadsheet (.xlsx, .xls, or .csv) with Address, City, State, and Zip Code columns. The tool calls the U.S. Census Geocoding API row-by-row and downloads the same file with latitude and longitude appended. Runs entirely in your browser — addresses are sent only to the public Census endpoint.
