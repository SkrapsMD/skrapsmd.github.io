Geocoder

Upload a spreadsheet of U.S. addresses and the tool will append latitude and longitude columns. Column names don't have to match exactly — we'll try to identify which columns hold the address, city, state, and ZIP code, and let you confirm or override the mapping. If a street address isn't available, we'll geocode using City + State + ZIP instead. Runs entirely in your browser; addresses are sent only to the U.S. Census public geocoding endpoint. Documentation on the Census Public Encoding Endpoint (https://www.census.gov/data/developers/data-sets/Geocoding-services.html), for the Nominatim Zip Centroid (https://nominatim.org/release-docs/3.6/develop/Postcodes/)<-->
